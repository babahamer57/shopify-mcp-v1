## 0 · איך מתחילים

1. **בקש מהמשתמש לצרף את ספר המותג** (brand book) — רצוי כקובץ `.md`. זה מקור האמת לכל דבר: אווטר, קול, פלטה (HEX), פונטים, מתחרים, התנגדויות, בידולים, מספרים מגיליון המחירים (שיעור 3). בלי ספר מותג — לא מתחילים לעצב.
2. **בדוק אם קיים `PLAN.md`** בתיקיית העבודה. אם כן — קרא אותו והמשך מהשלב האחרון שאושר. אם לא — צור אותו (שלב 0).
3. **בדוק מה מותקן**: Shopify CLI (`shopify version`), Node, הסקילים (סעיף 10), מחברים (Shopify, Higgsfield, MotionSites, Claude in Chrome).
4. **עבוד לפי 10 השלבים בסעיף 2.** בסוף כל שלב — **עוצרים ומחכים שהמשתמש יכתוב "מאשר"**. לא ממשיכים לבד.
5. **תמיד על עותק של התבנית** (Duplicate). לעולם לא על הערכה הפעילה.

- **תפקיד** — מפתח שופיפיי + Art Director

- **כלים** — אילו סקילים, מחברים ואתרים, ומתי כל אחד

- **זיכרון** — `PLAN.md`, כדי להמשיך מחר בשיחה חדשה
- **גבולות + מתי גמור** — מה אסור, ואיך יודעים שסיימנו

### שלד פרומפט 00 (כפי שהוצג בשקופית)
```
<role> Shopify developer + Art Director
<goal> the most responsive, wow store
<context> brand book = source of truth
<tools> skills · Chrome · ChatGPT
        21st.dev · Higgsfield · CLI
<process> 10 stages — STOP after each
<constraints> copy of the theme only
<done> 390px · PageSpeed 70+ · 3 wow
```
> הטקסט המלא של פרומפט 00 נמצא בקובץ השיעור (שקופית 4, כפתור "העתקה"). אם המשתמש מדביק אותו — הוא גובר על הסיכום כאן.

### "מתי גמור" (Definition of Done)
- נראה מושלם ברוחב **390px** (טלפון)

## 3 · מה הופך חנות למותג

### הקהל של 2026 — קשב של שנייה
הלקוח מגיע מטיקטוק/רילס. גולל מהרגל. לכן:
- **משהו זז** — וידאו, אנימציה, מוצר מסתובב. העין נעצרת על תנועה.
- **בכל גלילה — משהו חדש** — תמונה, וידאו, משפט, טבלה. לא שני קירות טקסט ברצף.
- **האתר מגיב** — לוחצים: קורה משהו. גוללים: משהו נחשף. מחליפים צבע: המוצר משתנה.

### 10 סימנים של מותג (מ-15 חנויות שנבדקו)
| הסימן | מה עושים |
|---|---|
| הירו בווידאו | לופ שקט 5–15 שניות, מצולם למותג (7 מ-13 דפי בית) |
| צילום אחיד | אותו רקע, אור ופלטה לכל המוצרים |
| טיפוגרפיה עם אופי | פונט כותרות אחד חזק, בגדול |
| קול המותג | בכל כותרת, כפתור, פופאפ ופוטר |
| תנועה עדינה | גלילה חלקה, כניסת סקשנים — לא הבהובים |
| אינטראקציה שמסבירה | נקודות על תמונה, השוואה, בורר צבע שמחליף מוצר |
| אמון עם מספרים | ביקורות אמיתיות, אחריות, ימי ניסיון |

- תמונות ספק (רקעים שונים, סימני מים, טקסט ענק על התמונה)
- דחיפות מזויפת ("24 שעות אחרונות" שמתאפס ברענון)
- ביקורות ומספרים בלי מקור ("15,000 לקוחות" מול 179 ביקורות)
- עומס אפליקציות (גלגל מזל + "מישהו מתל אביב קנה" + צ'אט ביחד)

## 4 · שופיפיי: ניהול, הגדרות, ערכה, עורך

### הניהול — פינה אחרי פינה
| פינה | מה זה | בשבוע הראשון |
|---|---|---|
| 🔍 חיפוש (Cmd/Ctrl+K) | מוצא הזמנה/לקוח/מוצר/הגדרה | מחפשים מכאן, לא בתפריטים |

| Orders | הזמנות, טיוטות, עגלות נטושות, הזמנה ידנית | הזמנה ידנית לניסיון (מוצר ← לקוח ← הנחה/משלוח ← Collect payment / Send invoice) |
| Products | מוצרים, וריאנטים, מלאי, קולקציות | מעלים מוצר ראשון |
| Customers | הזמנות, טלפון, כתובת, הערות, Segments | פותחים לקוח ראשון (את עצמך) |
| Content | Files, Menus, Metaobjects | לוגו + תפריט |
| Analytics | דוחות, Live View | מסתכלים על Live View |

| Sidekick | ה-AI של שופיפיי בתחתית | "כמה מכרתי השבוע?" |

### ערכת נושא — איך בוחרים
- **המלצה: חינמית של שופיפיי ממשפחת Horizon.**
- בסיס טוב כבר בדמו (ריווח, טיפוגרפיה, גלריה, עגלה).
- הפרטים הקטנים: כפתור, שדה כמות, בורר וריאנטים, תפריט בטלפון.
- **בודקים דמו בטלפון**, לא בדסקטופ.
- **לא ערכה פרוצה/ישנה** — לא מתעדכנת ופותחת פרצות.

### ערכה ועורך — צעד אחר צעד
1. Online Store → Themes → Add theme → Horizon → **Duplicate** (עובדים רק על העותק)
2. Customize → **Theme settings**: לוגו, Favicon 32×32, צבעים, פונטים
3. הוספה / הזזה / הסתרה של סקשנים (עין · גרירה · שכפול)
4. ⋯ → **Edit default theme content** — משנים מילים של התבנית ("סל" → "סל הקניות שלי", "אזל" → "אזל, עדכנו אותי")
5. **Preferences** → תמונת שיתוף + SEO (מה מופיע כששולחים קישור בוואטסאפ)

## 5 · דף הבית

### תפקיד הדף
- ממודעה **לא** נוחתים בדף הבית. מוצר אחד → מודעה לדף מוצר. הרבה מוצרים → מודעה לקולקציה.
- דף הבית **בונה אמון** ("מי אלה?") ו**הופך חנות למותג**.

### הסדר המקצועי
| # | סקשן | למה |
|---|---|---|
| 0 | בר הודעה | "משלוח חינם מעל X" — סיבת נטישה מס' 1 |
| 1 | הירו | מה, למי, למה — כותרת, משפט, **כפתור אחד** |
| 2 | פס אמון | משלוח · החזרות · תשלום בטוח · ביקורות |
| 3–4 | קולקציות + נמכרים ביותר | קיצור דרך לדף מוצר |
| 5 | מי אנחנו | 2–3 שורות, פנים אמיתיות, קישור לאודות |
| 6 | איך זה עובד | 3 שלבים, או וידאו |
| 7 | ביקורות | רק אמיתיות |

## 7 · דף המוצר

### נתוני מחקר (Baymard 2026)
- רק **38%** מדפי המוצר במובייל מקבלים "סביר" ומעלה
- **42%** מנסים להעריך גודל מהתמונות בלבד
- **60%** מחפשים מדיניות החזרות בדף המוצר
- **67%** מהאתרים לא מציגים עלות כוללת ליד הכפתור

### Product main section — בסדר הזה
1. **גלריה** — התמונה הראשונה מוכרת לבד
2. **כותרת + ⭐ ביקורות** — 2–4 מילים; כוכבים ומספר **רק אמיתי**
3. **4 בולטים: אימוג'י + יתרון** — **לפני המחיר** (קודם רוצים, אחר כך שואלים כמה)
4. **מחיר + Compare at price** — מחוק רק אם אמיתי
5. **ההצעה** — באנדל 1 / 2 (המומלץ מסומן) + מוצר נלווה במתנה
6. **כפתור** — בצבע היחיד מסוגו באתר
7. **שורת אמון** — משלוח · החזרות · תשלום בטוח

### הגלריה = מסע של 8 תמונות (סוגרת מכירה בלי טקסט)
| # | תמונה |
|---|---|
| 1 | מוכרת ומציגה — המוצר במלואו, ברמת מותג |
| 2 | בשימוש — אדם כמו האווטר |
| 3 | היתרון — אינפוגרפיקה עם 3 נקודות |
| 4 | התנגדות — ("מחטים? כואב?" — לא) |
| 5 | הוכחה חברתית — לקוח אמיתי, ביקורת אמיתית |
| 6 | גודל ומה בקופסה — ביד, באמת |
| 7 | השוואה — אנחנו מול "הרגיל" |
| 8 | הרגע שאחרי — התוצאה בחיים שלו |

**תהליך (פרומפט 6):** קלוד מקבל מוצר + אווטר + 3 התנגדויות → מחזיר 8 תמונות + פרומפטים באנגלית בסגנון צילום אחיד → ChatGPT מייצר תמונה-אחרי-תמונה עם תמונת המוצר האמיתית כרפרנס → טקסט בעברית בקנבה (עד 6 מילים, אותו פונט כמו באתר).

### בולטים: תכונות ❌ מול יתרונות ✅
- ❌ "סרום 30 מ"ל" · "מכשיר 0.5 מ"מ" — נכון, לא מזיז בלב
- ✅ "🪞 תפסיק לסדר את השיער לפני כל תמונה" · "⏱️ 3 דקות בערב — וזהו" · "🔬 רכיבים שנבדקו במחקרים, לא הבטחות" · "📸 תראה את השינוי בתמונות שלך"
- **נוסחה: אימוג'י + מה זה עושה לו בחיים** (כאב / פתרון / תוצאה) — לא מה יש בקופסה.

### ההצעה (מספרים מגיליון שיעור 3)
- מחיר + Compare at price (רק מחיר שבאמת היה)
- באנדל 2-1 — המומלץ מסומן (יותר רווח להזמנה)
- **מוצר נלווה במתנה במקום הנחה** — יותר ערך, לא שוחקים מחיר
- ביטול סיכון — החזרות, אחריות, "לא ראית שינוי — החזר"

### מתחת ל-main: קצב שמרענן את העין
הדגמה ↔ רגש ↔ הדגמה ↔ רגש, ואז הוכחות:
1. וידאו הדגמה (10–30 שנ')
2. רגש — משפט אחד במילים של האווטר
3. וידאו הדגמה — זווית אחרת (מה בקופסה / איך משתמשים)
4. רגש — מה ישתנה לו בחיים
5. GIF/אנימציה — לפני/אחרי, מנגנון, ציר זמן
6. רגש — הזהות: מי הוא יהיה
7. טבלת השוואה
8. ביקורות עם תמונות (רק אמיתיות)
9. למה אנחנו (3 בידולים)
10. התהליך (3 שלבים)
11. שאלות נפוצות (התנגדויות + מענים מהספר)

### קופי: 4 שורות, לא יותר
- כותרת שעוצרת + 4 שורות, ממורכז + ויזואל.
- דוגמה טובה: **"כמה שערות השארת על הכרית הבוקר?"** — "שלוש דקות בערב. מכשיר, שתי טיפות, וזהו. כל 30 יום — תמונה באותו אור. אתה תראה את השינוי בעצמך. לא נצטרך לשכנע אותך."
- **בדיקה: פסקה שתופסת יותר ממסך טלפון — חותכים.**

### טבלת השוואה
**מול "הרגיל" (הפתרון שהלקוח כבר מכיר), לא מול מתחרה בשם.** דוגמה SHUV:

| | SHUV | שמפו "נגד נשירה" | השתלה |
|---|---|---|---|
| מתחילים הערב, מהבית | ✅ | ✅ | ❌ |
| רכיבים שנבדקו במחקרים | ✅ | ❌ | — |
| רואים את השינוי בתמונות | ✅ | ❌ | ✅ |
| ליווי אישי 90 יום | ✅ | ❌ | ❌ |
| מחיר | ₪349 | ₪60 לחודש | ₪25,000 |

⚠️ **רק טענות אמיתיות.** ChatGPT המציא במוקאפ "בלי תופעות לוואי ✓ רק לנו" — מחליפים בשורות אמיתיות. המוקאפ הוא כיוון, לא מקור עובדות.

### מובייל
- **כפתור דביק** — פס תחתון עם מחיר + כפתור, מופיע כשהכפתור הראשי יוצא מהמסך
- כפתורים גדולים באזור האגודל
- החלקה בגלריה + נקודות שמראות כמה תמונות

### בעורך
Products → המוצר: מחיר + Compare at price, תמונות בסדר המסע → Customize → Products → Product information (= main section) → בלוק טקסט ל-4 הבולטים **לפני המחיר** → ההצעה (וריאנט "זוג" או אפליקציית באנדלים, מתנה בשורת טקסט) → Icons with text מתחת לכפתור → **בדיקה בטלפון**.

## 11 · שמונה כללים איך מבקשים מקלוד (ואיך קלוד צריך להתנהג)
1. **קודם שאלות** — "לפני שאתה בונה, תשאל כל מה שחסר"
2. **קודם תוכנית, בלי קוד** — "תסביר איך תעשה. עוד לא לכתוב קוד"
3. **המוקאפ הוא האמת** — סקשנים ממוספרים; "בדיוק כמו המוקאפ"; תיקון לפי מספר
4. **רשימת "לא"** — "לא זול, לא ניאון, לא דרופשיפינג, לא תבנית" (הכלי הכי חזק נגד גנרי)
5. **נועלים היקף** — "רק צבעים. אל תיגע בשום דבר אחר"
6. **שיבדוק את עצמו** — "תצלם, תשווה למוקאפ, תן ציון. פחות מ-10 — תמשיך"
7. **מרחיבים — לא בונים מקביל** — מוסיפים בלוקים לסקשן המוצר של התבנית (פחות באגים)
8. **נתקע בלולאה? עוצרים** — חוזרים לגרסה האחרונה שעבדה, ובונים משם (→ לכן commit/גיבוי אחרי כל סקשן שעובד)

## 12 · דוגמת SHUV (החנות שנבנתה בשיעור)
- **מוצר:** ערכת טיפול בנשירת שיער לגברים (מכשיר מיקרו-נידלינג 0.5 מ"מ + סרום 30 מ"ל, רוזמרין וקפאין, 90 יום). אווטר: גבר 27–40 שמתחיל לאבד שיער. קול: **ישיר, בלי הבטחות.** מחיר ₪349.
- **מחקר:** 4 מתחרים — RootFix (Shrine PRO + Heebo), Revivex (אותה ערכה בדיוק), Scandinavian (Dawn מותאמת, סטטי), Hims (פונט מותאם, כפתור אחד). **אף אחד לא משתמש בתנועה או עומק — שם SHUV נכנסת: המוצר מתפרק בגלילה.**
- **מוקאפ:** 2 סבבים ב-ChatGPT; תוקנו טענות מומצאות בטבלת ההשוואה.
- **בנייה:** 14 סקשנים על עותק Horizon, מחוברים למוצר אמיתי. סרטונים מ-Higgsfield, תמונות וסקשנים שלמים מ-ChatGPT.
  - טקסט עברי שזז על סרטון AI · חבילות עם תמונות
  - הגלילה פותחת את המוצר (וידאו AI)
  - "הטקס" — תמונת ChatGPT, השורות נחשפות בגלילה
  - סקשן שלם שעוצב ב-ChatGPT ונכנס כתמונה אחת
- **10 שלבי SHUV:** 1–3 ספר מותג · מחקר · מוקאפ (2 סבבים) → 4–5 Higgsfield (מתמונה אחת) → 6–7 Claude Code + CLI, קומפוננטה מ-21st.dev → Liquid → 8–9 בדיקות ותיקונים, המוצר בשופיפיי → 10 סבב פרימיום: טקסט שזז, אייקונים, סקשנים מ-ChatGPT, מעברים.
- קבצי השיעור: `example/01-research-result.md`, `example/02-mockup-prompt.txt`, `example/build-log.html`, `shuv-sections.zip` — אם המשתמש מצרף אותם, השתמש בהם כרפרנס מבני (**לא** להעתיק תוכן — זו חנות אחרת).

## 16 · נספח: ה-MCP Server בריפו הזה
הריפו `babahamer57/shopify-mcp-v1` מכיל שרת MCP ב-Python (`server.py`) שמחבר את קלוד ל-Admin API של החנות — **חלופה/תוספת למחבר הרשמי** (דרך 1 בסעיף 10).
- כלים: מוצרים (list/get/create/update/delete/count), הזמנות (list/get/count/close/cancel), לקוחות, קולקציות, מלאי ומיקומים, fulfillments, פרטי חנות.
- **אין בו כלים לתבניות (themes)** — את העיצוב בונים עם Shopify CLI (דרך 2).
- הגדרה: `.env` עם `SHOPIFY_STORE` + `SHOPIFY_ACCESS_TOKEN` (`shpat_...` מ-Custom App) → `pip install -r requirements.txt` → `python server.py` → `http://localhost:8000/mcp`. פירוט ב-`README.md`.
- ⚠️ לעולם לא לעשות commit ל-`.env` או לטוקן.
